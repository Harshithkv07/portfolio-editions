Plate I

Ride the Markets

A game

TypeScript · Phaser · Matter.jsIn development

Python · Claude APIOpen source

A terminal-based crisis-negotiation game. Its branching narrative runs on data structures implemented from scratch (a binary tree, a stack, a linked list and a directed graph), while the Claude API generates dialogue that responds to the state of the standoff.

Plate III

Semantic Search Engine

Information retrieval

Python · NumPy · SciPyOpen source

A search engine that matches meaning rather than keywords. Documents are represented through TF-IDF weighting and singular value decomposition, and a relevance-feedback loop, grounded in Bayesian inference and the Rocchio algorithm, re-ranks results as users mark the ones that help.

Plate V

AI-Integrated Fire Detection

Computer vision

Python · OpenCVOpen source

A real-time fire detection system. It analyses a camera feed with OpenCV and a Haar cascade classifier; when a fire persists past a threshold, it sounds an alarm and actuates a simulated sprinkler system, each on its own thread so detection never stalls.

Plate VI

Molecular Dynamics

Graph neural networks

Python · PyTorch Geometric · NumPy2024–25

A study of whether neural networks can predict which particles in a glass are about to move. Equivariant graph neural networks, built in PyTorch Geometric, forecast each particle’s mobility, trained on data from a Brownian-dynamics simulator written from scratch: 1,024 self-propelled particles, with KD-tree neighbour search keeping each step at O(N log N).
